# CPCB — Environmental Field Notes

A cinematic, scroll-led landing page inspired by circular editorial artwork and motion on [A24 — Films](https://a24.raviklaassens.com/). The page uses original copy, layout and interaction code, with locally stored environmental photography.

## Run locally

Open `index.html` directly, or serve this directory with any static web server. No build step or dependencies are required.
